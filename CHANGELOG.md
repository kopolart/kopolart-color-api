## [1.0.0] - 2026-11-10

### Added

- Public documentation for `/api/color/{hex}`, `/api/complementary-color/{hex}`,
  `/api/similar-colors/{hex}`, `/api/similar-palettes/{hex}` and the legacy
  `/api-color/{hex}`.
- OpenAPI 3.1 specification with schemas and verified examples.
- Interactive Redoc reference for GitHub Pages.
- Quick-start and full endpoint reference.
- Error, rate-limit and caching guides.
- Runnable examples in cURL, JavaScript, Python and PHP.
- CI workflow that lints the OpenAPI document.
- MIT license, contribution guide and security policy.
